# Skills 3D del proyecto

Skills locales instaladas en `.opencode/skills/` para apoyar el trabajo con
Blender, modelos estilizados, optimización y WebAR. Reinicia OpenCode después de
instalarlas para que las detecte.

| Skill | Uso previsto |
| --- | --- |
| `blender-3d` | Flujo general de modelado y escenas Blender. |
| `blender-modeling` | Modelado y organización de objetos en Blender. |
| `stylized-art-direction` | Dirección visual estilizada y coherencia de formas y color. |
| `organic-sculpting` | Formas orgánicas para la abeja y elementos naturales. |
| `retopology-optimization` | Reducir geometría y preparar modelos para tiempo real. |
| `pbr-materials-texturing` | Materiales y texturas PBR. |
| `cinematic-lighting` | Iluminación y composición para renders. |
| `blender-python` | Automatización de escenas con la API Python de Blender. |
| `webar-gltf-pipeline` | Exportación y revisión de GLB para WebAR. |
| `3d-quality-assurance` | Revisión de mallas, escala y exportaciones. |

Las skills son instrucciones de apoyo, no evidencia de autoría ni validación de
los modelos. El resultado debe revisarse en Blender y en el destino WebAR.
