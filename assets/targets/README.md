# Etiqueta objetivo de MindAR

`etiqueta-sakpokaab.svg` es la fuente editable de la etiqueta. El PNG de 1200 ×
1600 px se compiló con MindAR Image Targets Compiler 1.2.5 y dio como resultado
`etiqueta-sakpokaab.mind` (un target, índice `0`).

## Impresión y uso

- Imprimir en A5 o A4 conservando la proporción 3:4; no recortar el marco.
- Para el primer escaneo, colocar la etiqueta plana y con luz pareja, sin reflejos
  ni sombras fuertes.
- Si se edita el SVG, volver a exportarlo a PNG y recompilar ese PNG en el
  [Image Targets Compiler de MindAR](https://hiukim.github.io/mind-ar-js-doc/tools/compile/).
- El archivo `.mind` debe corresponder exactamente al PNG servido por la
  experiencia AR.

El visor incluye una vista de la etiqueta en el botón **Ver etiqueta**. Para
probarla con un solo teléfono, imprimirla; para una prueba rápida, abrirla en otra
pantalla.
